# Basile

App perso d'entretien des plantes : savoir quoi arroser et quand, sans fioritures.

- `index.html` : prototype v1, une seule page, données en local (localStorage).
- `CLAUDE.md` : contexte du projet, fonctionnalités à construire et architecture cible.

Pour tester le prototype : ouvrir `index.html` dans un navigateur.
